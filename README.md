## 🧠 4. Professional Reflections (STAR Method)
To demonstrate structural learning, I have compiled formal self-reflections using the **STAR (Situation, Task, Action, Result)** method—a highly recognized behavioral evaluation framework in the tech industry.

### 📁 Reflection A: Coding in Markdown
* **Situation (S)**: As part of the PRP370S Project Presentation 3 curriculum, I was tasked with designing a professional digital portfolio. While I had basic experience writing text readme files, I had never formatted highly detailed technical documents, tables, blocks, and indicators using Markdown.
* **Task (T)**: I needed to translate my traditional formatted PDF CV into a highly readable, clean, and semantic Markdown structure (`CV.md`) that fits standard developer repositories and is highly parseable by modern web renders.
* **Action (A)**: I studied the GitHub Flavored Markdown (GFM) specification, mastering tables, lists, text styling, and custom blockquotes. I utilized code snippets to highlight technical skills, and structured my professional history into logical hierarchies with headers. I validated my formatting using local preview tools before pushing the commits to ensure consistent render output across various devices.
* **Result (R)**: I successfully constructed a professional, standard GFM CV that serves as an open-source, easily maintainable professional record. This taught me the value of structured text files in engineering environments, ensuring my credentials are easily searchable and highly readable in a professional repository.

### 📁 Reflection B: Mock Interview Video Experience
* **Situation (S)**: Preparing for software engineering internships requires polished verbal presentation skills, composure under pressure, and the ability to clearly articulate technical solutions. The PRP370S curriculum included a mock interview requirement to evaluate these non-technical competencies.
* **Task (T)**: I had to participate in, record, and evaluate a comprehensive mock interview simulation (`Interview.mp4`). I needed to demonstrate how my core capabilities (problem-solving, event leadership) align with the requirements of a software developer intern.

During the interview, I highlighted my background as a Floor and Team Lead (2024 - 2026) to demonstrate my ability to coordinate teams, solve unexpected system crises, and communicate clearly under pressure.

By hosting my interactive CV, STAR reflections, and interview video on a single responsive platform, I have created a standout, professional workspace presence that is fully ready to share with recruiters.

## 🛠️ Local Setup & Deployment Instructions
To run this project locally or update your own deployment:

1. **Clone the repository**:
   ```bash
   git clone https://github.com/your-username/githubrepoeportfolio.git
   cd githubrepoeportfolio
   ```
2. **Open locally**:
   Double click the `index.html` file to run the web application directly in your browser.
3. **Deploy to GitHub Pages**:
   - Push your code to your main branch on GitHub.
   - Go to your repository settings on GitHub.
   - Click on the **Pages** tab in the sidebar under "Code and automation".
   - Under "Build and deployment", select **Deploy from a branch** as the source.
   - Select your branch (e.g., `main`) and folder (e.g., `/ (root)`), then click **Save**.
   - Your site will be live at `https://<your-username>.github.io/<your-repository-name>/` in a few minutes!
